# **App Name**: TradeSim

## Core Features:

- Simulated Portfolio: Create and manage a virtual stock portfolio with a set amount of fake money.
- Real-Time Stock Data: Display real-time stock prices and market data (using a free API).
- Buy/Sell Stocks: Allow users to buy and sell stocks within the simulated environment.
- Order Tool: Reason about how to choose reasonable order sizes in the simulation given different capital allocation strategies. Then execute realistic simulated trades
- Portfolio Tracking: Track the performance of the portfolio over time with charts and graphs.
- Watchlist: Allow users to create a watchlist of stocks to monitor.
- News Feed: Integrate a news feed to provide relevant market news (using a free API).

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), reminiscent of traditional financial documents, instilling trust and seriousness.
- Background color: Light gray (#F5F5F5), provides a neutral backdrop, ensuring readability and reducing eye strain during prolonged use.
- Accent color: Green (#4CAF50) is used to indicate gains or positive changes in the portfolio, creating a clear visual cue.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, 'Inter' (sans-serif) for body text.
- Use clean, modern icons to represent different stocks, sectors, and actions.
- A clean and intuitive layout, prioritizing key information and ease of use.
- Subtle transitions and animations to enhance user experience.
