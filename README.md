# TradeSim: AI-Powered Paper Trading Simulator

TradeSim is a sophisticated paper trading application designed to simulate a realistic stock market experience. It's built with a modern tech stack and features AI-powered tools to help users make informed trading decisions without any real-world risk.

## Key Features

- **Real-Time Stock Simulation**: Experience a dynamic market with stock prices that update continuously.
- **Portfolio Management**: Start with virtual cash, buy and sell stocks, and track your portfolio's performance over time with detailed candlestick charts.
- **Interactive Watchlist**: Monitor your favorite stocks with sparkline charts that visualize recent price action.
- **AI-Powered News Analysis**: Get instant sentiment analysis and market impact summaries for the latest financial news.
- **AI Order Assistant**: Receive intelligent order size suggestions based on your chosen capital allocation strategy and personal risk tolerance.
- **Comprehensive Order History**: Review all your past trades in a detailed transaction log.
- **Sleek, Modern UI**: A professional and responsive interface built with ShadCN UI and Tailwind CSS, including support for light and dark modes.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (with App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **AI/Generative**: [Genkit](https://firebase.google.com/docs/genkit)
- **Charting**: [Lightweight Charts™ by TradingView](https://www.tradingview.com/lightweight-charts/)

## Getting Started

To run the application locally, follow these steps:

1. **Install Dependencies**:
   Open your terminal in the project root and run:
   ```bash
   npm install
   ```

2. **Run the Development Server**:
   Once the dependencies are installed, start the Next.js development server:
   ```bash
   npm run dev
   ```

3. **Open the Application**:
   Open your browser and navigate to [http://localhost:9002](http://localhost:9002).

You can log in with the following credentials:
- **Email**: `trader@tradesim.com`
- **Password**: `password`
